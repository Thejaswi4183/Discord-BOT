# Discord Bot

A Discord bot built with Python and discord.py that supports slash commands.

## Features

- Slash commands including ping, roll dice, clear messages, user info, reminders, and more  
- Easy to extend with new commands

## Setup Instructions

1. Clone this repository  
2. Create a `.env` file in the project root with your bot token:  
   ```env
   TOKEN=your_bot_token_here
    ```
3. Install required packages:

    ```bash
    pip install -r requirements.txt
    ```
4. Run the bot:
   ```bash
    python bot.py
   ```
   
## Usage

Use the slash commands in your Discord server where the bot is added. Commands include /ping, /say, /remindme, /clear, and others.

Feel free to submit issues or pull requests to add new features or improve existing ones.
